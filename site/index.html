A small interactive example Get the sample HTML files

The file is finished. Keep it useful.

Use the HTML your agent or script already produces. Each document keeps its original contents, with a title and type you can search later.

  1. Publish a file

    Give an HTML file a title and type. HTML Inbox checks compatibility, saves it and prints a document URL. 

    html-inbox publish ./report.html \
  --title "Migration report" \
  --type report

  2. Read in your browser

    Open the URL to read the document in a sandboxed preview. Reports can include inline styles, scripts and interactive controls.

    Write HTML that works in the viewer

  3. Find it again

    Search by title, type or source file. The background viewer stays running after you close the terminal.

    Manage the viewer

Read locally. Or on your home server.

Choose who can reach the live inbox. Network readers can browse, search and open documents. Publishing and deletion stay in your local CLI.

Commands and reader access for each live viewer mode
Where you read Start the viewer Who can read
This machine html-inbox viewer Loopback on first startup. Later starts reuse your saved settings.
Local network html-inbox viewer --lan Everyone who can reach the port. No password or login.
Your tailnet html-inbox viewer --tailscale HTTPS through an existing Tailscale client, under your tailnet policy.

Each mode serves the complete live library. Stop the viewer before changing modes. Understand reader access and storage.

Start before anyone logs in

Install a systemd system service on Linux or a LaunchDaemon on macOS. Setup needs administrator privileges; the viewer runs as your selected normal user.

Share a static snapshot

Export your library or publish it to a Cloudflare Pages project you own. The unlisted snapshot URL is a bearer link: anyone with it can read and reshare the snapshot.

Export and publish snapshots

Document code stays in its preview.

Stored HTML renders in a sandboxed iframe without same-origin access. A restrictive content policy limits what it can load and do.

Validation reports compatibility problems. It does not sanitize document code. Keep styles and assets inside your HTML, and share the library with readers you trust.
