HTML Inbox documentation

Write HTML that renders

Keep each report self-contained. HTML Inbox stores the original file without rewriting it, and the served document policy controls which resources can run.

Embed resources in the document

HTML Inbox does not copy files beside your source. A reference to chart.png, styles.css, or app.js produces an advisory warning and the viewer blocks the request. Paths beginning with ./, ../, or / have the same limitation.

Resource Supported approach
CSS Use a <style> element. External stylesheets and CSS network requests are blocked.
JavaScript Use an inline <script>, or a supported CDN entry below. Attach events from the script.
Images, media, fonts Embed the bytes in a data: URL. Embed every candidate in srcset.
SVG symbols Define the symbol in the same document and reference <use href="#symbol">.
Frames and objects Blocked, including data URLs. 
<style>
  body { font: 16px/1.6 system-ui; padding: 2rem; }
  .complete { color: #176241; }
</style>
<button id="complete">Mark complete</button>
<script>
  document.querySelector('#complete').addEventListener('click', (event) => {
    event.currentTarget.classList.add('complete');
  });
</script>

Use supported CDN scripts

These script entry URLs are supported by the document CSP.

  • https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4
  • https://cdn.tailwindcss.com, including its supported ?plugins= query.
  • https://cdn.jsdelivr.net/npm/mermaid@11/dist/mermaid.esm.min.mjs

Use the Mermaid entry in a module script or an inline module import. 

<pre class="mermaid">flowchart LR
  Generate --> Publish --> Read
</pre>
<script type="module">
  import mermaid from 'https://cdn.jsdelivr.net/npm/mermaid@11/dist/mermaid.esm.min.mjs';
  mermaid.initialize({ startOnLoad: true });
</script>

Other remote script URLs produce warnings and are blocked. An allowed script host does not make its images or stylesheets allowed. CDN scripts require internet access and may change within their allowed major version. Offline rendering is not guaranteed.

Choose supported navigation

HTTPS links, relative links, and fragment links in <a href> and <area href> are allowed. Relative links resolve against the stored document URL, not the original source directory. Use fragments for sections within the report.

Document links stay inside the preview frame. Popup, _blank, and top-page navigation permissions are absent. Literal javascript:, vbscript:, and navigable data: URLs are rejected, as are unsupported anchor schemes and <meta http-equiv="refresh">.

Understand warnings and errors

A validation error prevents publishing. A warning means the source uses a resource or feature the served CSP blocks; the document is still stored. Fix the source and publish a new record when a warning affects the report.

Typical warnings include relative assets, external assets outside the script allowlist, inline event attributes, and <base>. Validation parses markup but does not inspect every CSS request or reliably detect URLs assembled by script. The browser policy still applies to those requests.

Know the isolation limits

Documents render in a sandboxed iframe with allow-scripts only. They receive an opaque origin and cannot access the viewer DOM or its same-origin storage. The CSP blocks fetch connections, forms, nested frames, objects, and non-data media, while allowing inline scripts and the supported CDN entries.

Validation is a compatibility and policy check, not sanitization. Allowed script can consume CPU or memory and can navigate its own frame. Author markup or script can put content in a destination URL or override the default no-referrer policy.

Read reports through the served viewer or properly configured static host. Opening a stored HTML file directly from disk does not provide the viewer's response headers and CSP. See security limits before opening an untrusted report.
