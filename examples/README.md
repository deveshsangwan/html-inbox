# Try the examples

Publish [the report](report.html), [the support dashboard](dashboard.html), or
[the Mermaid diagram](mermaid.html) into your local HTML Inbox.

[Commands, things to try, and actual viewer screenshots](../docs/examples.md)
are in the examples guide. Each HTML file includes its content and styles.

All three examples follow System appearance when opened standalone and accept the
viewer's Light or Dark override. The Mermaid chart keeps its authored light
palette while its surrounding text follows the viewer. The report and dashboard
switch their text, controls, tables, and surfaces together.

For new documents, copy the skill's [self-contained appearance template](../skills/html-inbox/assets/document-template.html)
and follow the [appearance contract](../skills/html-inbox/references/document-appearance.md).
It includes a white paper preview whose text and background remain paired.
