Older binaries reject the new format safely, so upgrade participating managed workers and CLIs together. This is not mixed-version managed liveness compatibility. Ledger, runtime-record and replication wire schemas do not change.

The candidate is written, synced, closed and reopened before publication. After linking, and again after removing the candidate, the retained file handle is synced before the checked parent directory. Recovery uses the same order.
